# ALBASMA Tours & Travels (البسمة للسياحة والسفر)

> Ultra-Luxury Pilgrimage & Bespoke International Expeditions Web Application

A modern, high-performance, 5-page React web application built with Vite, Tailwind CSS, Framer Motion, and Lucide Icons for **ALBASMA Tours & Travels**, headquartered in Melapalayam, Tirunelveli under Proprietor A. Abdul Rahman.

---

## 🌟 Key Features

- **5 Dedicated Full-Feature Pages**:
  1. **Home (`/`)**: Animatic 3-slide hero carousel, continuous live marquee ticker, glassmorphic booking filter console, 4 sacred pillars, bento destination showcases, transparent package pricing cards, and founder credibility profile.
  2. **Hajj & Umrah (`/hajj-umrah`)**: Sacred pilgrimage luxury portal featuring 4 curated packages (*VIP Executive Umrah*, *Deluxe Pilgrim Umrah*, *Ramadan Last 10 Days Special*, and *Annual Holy Hajj Delegation*), guided Ziyarah milestone circuits, and interactive FAQ accordion.
  3. **International Tours (`/destinations`)**: Curated luxury escapes across Turkey & Ottoman heritage, Dubai & Emirates, Malaysia & Singapore, Al-Aqsa & Jordan, Kashmir, and Kerala backwaters with interactive category filtering.
  4. **Our Services (`/services`)**: Full-spectrum travel facilitation matrix (Air Ticketing, Saudi Nusuk Visas, Certificate Attestation & Apostille, Online Passport Tatkaal, Luxury Chauffeur Fleet, Forex, Travel Insurance) plus 4-step attestation roadmap.
  5. **About & Contact (`/contact`)**: Melapalayam Head Office coordinates, permanent Saudi operations desk in Makkah & Madinah, and priority reservation form with direct WhatsApp dispatch.
- **Ultra-Luxury Glassmorphic Design System**: Imperial Voyage palette (midnight teal `#00282b`, `#073F43`, ocean teal `#0E696A`, champagne gold `#D4AF37`, `#E5C378`, and pearl white `#F8FAF8`).
- **Rich Animations**: Framer Motion route transitions, active navbar underlines, `@keyframes goldShimmer` text, live marquee ticker, and smooth hover micro-interactions.
- **Universal WhatsApp Booking Modal**: 1-click inquiry dispatch from any page directly to the Melapalayam reservations desk (`+91 96773 12228`).
- **100% Mobile Responsive**: Fluid typography, touch-friendly 44px+ tap targets, accessible hamburger menu drawer, and zero horizontal overflow.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/risa113/al-basma-travels.git
   cd al-basma-travels
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
